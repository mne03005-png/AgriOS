# AgriOS V1.0 响应式设计基线

一套 Vue 应用覆盖三端：手机 `<768px` 使用单列、底部五入口导航、44px 触摸目标和全屏危险确认；平板 `768–1199px` 使用双栏工作区；电脑 `>=1200px` 使用 240px 左侧导航、顶部上下文和三栏工作台。

统一 App Shell 显示农场、canonical role、在线/离线状态、告警、用户退出，并按角色生成工作区入口。目标视口为 375×812、768×1024、1024×768、1366×768、1920×1080。

CSS/构建静态契约已通过。当前环境未安装 Playwright，未执行真实浏览器截图、溢出和交互测试，五视口视觉验收状态为 BLOCKED，不宣称已通过。
