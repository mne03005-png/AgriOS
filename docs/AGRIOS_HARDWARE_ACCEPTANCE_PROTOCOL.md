## 1. 验收规则

每台设备执行“文件验收 → 外观/铭牌 → 台架功能 → 72 h 老化 → 结论”。任何安全、频段、身份唯一性或防护缺陷均为阻断项，不允许以“现场再修”放行。

| 结论 | 定义 |
|---|---|
| PASS | 所有阻断项及门槛通过，证据完整 |
| CONDITIONAL | 仅非安全、非功能缺陷；有责任人和关闭日期，现场安装前必须复验 |
| REJECT | 型号/频段/电压错误，安全保护失败，身份重复，功能或老化失败 |

证据编号规则：`PO批次-资产ID-测试号`。照片必须同时包含设备、序列号标签和测试仪表读数；密码、AppKey、SIM PIN 不得入镜。

## 2. 通用到货检查

- [ ] 采购订单、装箱单、发票、序列号、合格证和质保一致。
- [ ] 中国现场使用的无线型号/频段资料齐全，LoRa 明确为 CN470/470M。
- [ ] 外壳、端子、天线座、密封圈和铅封无损；无进水、锈蚀或拆修痕迹。
- [ ] 电源极性、额定电压、功耗和附件与订单一致。
- [ ] 固件可从厂商渠道验证，版本无已知阻断性安全公告。
- [ ] 每台设备序列号、MAC、IMEI/DevEUI 唯一，已录入资产表。

由持证电工执行。组件、MPPT、电池/BMS、SmartShunt、DC/DC、熔断器、SPD 和箱体作为一个系统验收。

| 项目 | 方法 | 通过门槛 | 实测/证据 |
|---|---|---|---|
| 组件铭牌 | 核对 Voc/Vmp/Isc/Imp/Pmax | 与设计一致；最低温修正 Voc <100 V | |
| 绝缘/极性 | 上电前测量 | 极性正确，绝缘满足当地规范 | |
| 保护 | 查线径、DC 分断能力、保险/SPD | 与计算书一致；电池正极近端有主保险 | |
| MPPT | 日照下观察阶段/电流 | 识别 24 V；LiFePO4 参数经电池厂家批准 | |
| BMS | 模拟充放电禁止 | 能切断许可，负载不绕过 BMS | |
| SmartShunt | 零点、满充同步、已知负载 | 电流方向正确；误差记录并在允许范围 | |
| DC/DC | 空载/满载/4G 峰值 | 5 V 稳定；Edge 不重启；温升可接受 | |
| 动力冲击 | 泵/等效负载启动 | 通信母线不复位，最低电压有记录 | |
| 低电量 | 模拟 SOC 阈值 | 禁止启泵，Gateway/急停/关阀仍可用 | |
