# AgriOS 第一次真实现场部署作业书

> 目标：以单 Zone 为安全起点，在 Day0–Day7 完成硬件安装、真实 MQTT 上线、一次受控自动灌溉和验收。

## 1. 人员与停止权限

| 角色 | 责任 | 有权停止 |
|---|---|---|
| 现场负责人 | 作业许可、天气、进度、验收 | 全部作业 |
| 持证电工 | 光伏、配电、绝缘、接地、泵控制 | 一切带电测试 |
| 水利/灌溉人员 | 泵曲线、管路、阀、流量和防空转 | 一切通水测试 |
| AgriOS 工程师 | 注册、MQTT、Edge、数据与报告 | 自动控制和联网测试 |
| 农场操作员 | 手动操作、巡检、异常反馈 | 灌溉运行 |

雷雨、大风、地下管线不明、箱体进水、接地不合格、泵可能空转、急停失败或 Device ID 不一致时立即停工。

## 2. Day0：设备检查与台架联调

### 硬件

- [ ] 按最终采购清单逐件核对型号、CN470、序列号、外壳、合格资料和备件。
- [ ] 测量电池电压、阀线圈电阻、接触器/过载整定和各支路保险。
- [ ] 空载核对 PV Voc/Isc，使用项目最低温修正值复核 MPPT 100 V 上限。
- [ ] 检查 SIM ICCID/APN/套餐，分别通过移动、联通访问 MQTT/TLS。
- [ ] 给所有设备贴 Device Key、额定电压和二维码，不含任何密钥。

### 台架

- [ ] 创建 Tenant/Farm/Field/Zone A–D 和全部 Device。
- [ ] 完成 UR35、UG65、Edge、LSE01、EM300-TH、UC300 配置并备份。
- [ ] 真实 MQTT 连续运行 4 h：无认证失败，遥测、battery、RSSI/RSRP、lastSeenAt 正常。
- [ ] 拔掉蜂窝 1 h：Edge 缓存、恢复补传和去重通过。
- [ ] 不接水泵主回路，验证急停、手/停/自动、阀反馈、超时和缺水输入。

Day0 放行条件：所有阻断项通过；红线图、接线图、端子表、安装坐标和天气窗口已确认。

## 3. Day1：现场安装

### 上午：土建、管路和支架

1. 安全交底、放线、确认地下管线和排水方向。
2. 安装泵基座、过滤器、止回阀、压力表、流量计、总阀和 Zone 阀组；按规定压力试压。
3. 安装控制箱、太阳能支架和 3–5 m 网关杆；结构和防雷由专业人员验收。
4. 埋设 Zone A 土壤节点，探针距滴头 0.25–0.40 m、避开田埂/石块；B–D 可安装但不参与首次自动控制。

### 下午：电气与通信

1. 依次完成接地、箱体、蓄电池、MPPT、PV、DC 支路；上电顺序服从厂家手册。
2. 安装 UR35、Edge、UG65 和天线；馈线 ≤3 m，防雷器/格兰头/滴水弯合格。
3. 连接急停、模式选择、缺水、流量和阀反馈；强弱电分槽，交叉 90°。
4. 先不接泵主触点，检查 24 V/5 V 母线和 Edge 4G 发射时最低电压。

Day1 记录：安装坐标、朝向、高度、线缆号、端子号、铭牌和全景/细节照片。

## 4. Day2：设备上线与校准

1. UR35 主 SIM 上线，记录 RSRP/RSRQ/SINR；切换备 SIM 并记录恢复时间。
2. UG65 确认 CN470 通道；逐节点 OTAA Join，记录最差 Zone RSSI/SNR 和丢包。
3. Edge MQTT/TLS 上线；AgriOS 中 Gateway、Zone A 传感器和控制器显示 ONLINE。
4. 土壤传感器与现场标准方法做湿/干两点校准；空气温湿度同箱对比 2 h。
5. 流量计执行定量容积校验；阀逐个点动并核对反馈，泵仍保持手动/停止模式。
6. 连续采集 24 h，数据完整率目标 ≥99%，时间差 <2 s，重复 messageId = 0。

## 5. Day3：首次自动灌溉

### 启动前 Go/No-Go

- [ ] 急停实测有效，模式为 STOP；阀为常闭安全态。
- [ ] 水源充足、过滤器清洁、泵已灌引水、缺水保护有效。
- [ ] 电池 SOC ≥60%，母线电压正常，天气无雷雨。
- [ ] Zone A 阀反馈、流量计和压力表正常；其他 Zone 禁止启动。
- [ ] 自动任务设置最大 120 s、单 Zone、一次性 idempotency key；现场两人在场。

### 执行

1. 手动打开 Zone A 阀并短时点泵，确认流向、压力、流量和无泄漏后停止。
2. 将模式切至 AUTO；在 AgriOS 创建 120 s 灌溉任务。
3. 核对顺序：开阀确认 → 启泵 → 稳定流量 → 到时停泵 → 关阀确认。
4. 任何无流量、超压、阀反馈不符、通信丢失或母线跌落立即急停。
5. 记录 commandId、各阶段时间、总水量、压力、执行反馈和审计事件。

通过条件：只执行一次；120 s + 容差内自动关闭；任务 COMPLETED；用水量与流量积分一致；无泄漏、空转和重复动作。

## 6. Day4–Day6：长稳与故障演练

### Day4 网络中断

- 双 SIM 断网 2 h，确认本地采集、缓存、安全规则和现场告警。
- 恢复备 SIM，确认实时优先、完整补传、重复为 0、过期命令不执行。

### Day5 能源与异常

- 遮断 PV 输入/使用测试开关模拟低 SOC，验证 Warning/Critical 和泵启动闭锁。
- 模拟传感器断线、阀反馈不一致和无流量；确认故障分类、自动关闭和恢复记录。

### Day6 运行分析

- 计算在线率、MQTT 成功率、数据完整率、灌溉成功率、异常次数和平均恢复时间。
- 对比 AgriOS Daily Report/Field Health Score 与原始记录。
- 清除临时账号、调试热点和测试命令；备份最终配置。

验收结论只能是：通过、有条件通过、不通过。有条件通过必须写明不影响安全的遗留项、负责人和完成日期；任何安全保护失败只能判定不通过。

## 8. 回退方案

- Cloud/MQTT 故障：保持 LOCAL/AUTO 最后批准规则或切 MANUAL，由现场人员操作。
- Edge 故障：模式切 STOP，关闭泵，阀恢复常闭；更换预制 SSD/Edge 后重新验证。
- UG65/LoRa 故障：禁止新的远程自动灌溉；现场硬接线保护仍有效。
- 电源故障：动力母线优先断开，保留 Gateway/告警；电压不稳定时不得反复启泵。
- 泵阀故障：急停、断开并上锁挂牌，禁止通过软件反复重试。
