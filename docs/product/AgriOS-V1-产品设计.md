# AgriOS V1 产品设计

## 项目定位

AgriOS V1 面向家庭农场、种植大户和合作社的真实农田管理场景，先从一块洋葱地样板做起，逐步扩展到合作社和县域农业服务平台。

核心不是设备本身，而是围绕地块建立完整数字档案：

地块 -> 种植季 -> 农事记录 -> 农资投入 -> 设备数据 -> 作业服务 -> 成本收益

## V1 核心模块

1. 用户：基础用户、手机号、角色、所属农场。
2. 农场/组织：家庭农场、合作社、农业公司。
3. 地块：面积、位置、土壤、水源、灌溉方式、土地来源、轮作建议。
4. 种植季：作物、品种、年份、季节、播种和采收时间、状态。
5. 农资记录：种子、化肥、农药、农膜、滴灌带等投入品记录。
6. 农事记录：播种、浇水、施肥、打药、无人机、农机、人工、采收等。
7. 设备：土壤湿度、水泵、阀门、流量、水位、气象站、网关。
8. 传感器数据：设备上报的湿度、温度、流量、水位等数据。
9. 灌溉记录：手动、自动、定时灌溉记录。
10. 服务信息库：无人机飞手、农机服务、技术员、农资渠道。
11. 成本记录：种子、肥料、农药、人工、无人机、农机、灌溉、电费、租地等。
12. 轮作提醒：基于去年作物和当前作物给出基础提醒。

## 第一阶段边界

V1 只做记录、管理、设备接入、灌溉控制、成本统计和服务信息库。

暂不做农资电商、农药在线销售、支付、物流、复杂 AI、全国平台、政府大屏、区块链溯源。

## 典型流程

1. 创建农场或合作社。
2. 创建地块档案。
3. 为地块创建本年度种植季。
4. 记录种子、肥料、农药等农资投入。
5. 记录播种、浇水、施肥、打药、采收等农事。
6. 绑定水泵、阀门、传感器等田间设备。
7. 接收传感器数据，生成灌溉提醒或控制指令。
8. 记录灌溉过程和水量。
9. 汇总种植季成本，后续扩展产量、收入和利润。

## 预留扩展

- 多农户、多地块、多作物的合作社管理。
- 农事任务派发和执行状态。
- 无人机、农机服务订单。
- 农资渠道合规档案。
- 产量、收入、利润和亩均收益。
- 微信小程序和农户端。
- AI 灌溉建议、病虫害提醒、产量预测。
