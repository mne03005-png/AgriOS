# AgriOS 小菜园正式部署 BOM

版本：Phase27 / 预算基准日 2026-08-03  
币种：人民币，含税预算区间，不含土建、人工、运费、运营商年费和不可预见地下工程。采购前必须取得不少于两家供应商的正式报价、合格证、质保条款和无线型号核准信息。

## 1. 选型原则

- 推荐方案用于无人值守验证：工业 LoRaWAN 网关 + 独立边缘计算机 + 4G/5G 备链路。
- Raspberry Pi 方案仅作为受控试点的低成本边缘计算替代，不直接驱动水泵或承担硬安全联锁。
- 中国现场使用与当地许可相符、具有合法型号核准的 CN470/相关频段设备；不得照搬海外 EU868/US915 型号。
- 所有室外设备最低 IP65，埋地/阀盒内接头 IP67/IP68；泵阀电源统一优先采用 24 VDC 安全特低电压。
- 表中品牌/型号只说明可核验的规格等级，允许采购等效或更高规格产品。

## 8. 预算汇总与采购建议

| 方案 | 设备材料预算 | 适用范围 |
|---|---:|---|
| 受控经济型（Pi 5、保留硬联锁） | ¥24,000–34,000 | 有人值守的小菜园验证 |
| 推荐工程型（工业边缘、工业路由） | ¥32,000–48,000 | 7×24 小时 Field Pilot |
| 预留 10% 不可预见费后 | ¥35,000–53,000 | 项目立项预算 |

不得为压低预算删除：硬急停、缺水保护、主保险、分路保险、防反接、浪涌保护、接地、阀门常闭安全态和流量计。可后置采购：第二空气温湿度、PAR 高精度版本、备用节点之外的额外库存。

## 9. 到货验收

逐件核对型号、频段、额定电压、序列号、合格证、IP 等级、质保；抽检电磁阀线圈电阻、传感器零点、箱体密封和电池容量。无线设备若没有合法频段/型号文件，电池若没有 BMS 与运输/安全资料，直接拒收。
